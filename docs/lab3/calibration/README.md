# Калібрування судді (Лабораторна 3, крок 02)

14 випадків = 10 справжніх артефактів фабрики (`docs/lab3/runs/*/patch.diff`) + 4 навмисно зіпсовані копії справжніх змін
(`spoiled/`, щоб серед міток були `fail`, інакше каппа не визначена). Кожен випадок — один артефакт проти одного
критерію з [`../criteria.jsonl`](../criteria.jsonl). Склад — [`cases.jsonl`](cases.jsonl), текст для читання — [`cases.md`](cases.md).

**Розмітка — автора, 2026-11-08, ДО будь-якого запуску судді** (цей файл і `labels.jsonl` закомічені раніше за результат).

Зіпсовані: 11 — `it.skip` у тесті `t-04`; 12 — змінено `RRF_K` у забороненому `src/rag/rrf.ts`; 13 — із `t-02` прибрано
зміну самого `src/rag/cite.ts`, лишився тільки тест; 14 — до `t-07` додано зміну `scripts/baseline.ts`.

**Чесно про дві проходи розмітки.** Перша (`first_pass` у [`labels.jsonl`](labels.jsonl)) дала `fail` на всіх п'яти
критеріях виду «файл X не змінено». Перш ніж фіксувати, агент уточнив лише значення мітки (pass = X справді не змінено),
не називаючи жодного правильного випадку; автор переглянув усі 14. Остаточна — поле `mine`; змінились випадки 1, 3, 4, 6, 10
(fail → pass) і 13 (pass → fail). Судді на той момент ще не запускали, і далі розмітка не змінюється: розбіжності лікуються
правкою рубрики.

Запуск судді: `npx tsx --env-file=.env.local scripts/harness/calibrate.ts --run 1` → `results-run1.jsonl`;
згода: `npx tsx scripts/kappa.ts docs/lab3/calibration/results-run1.jsonl`.
