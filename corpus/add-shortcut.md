# Додавання корисних скорочень (aliases)

## Опис

Створення скорочених команд (аліасів) для швидкої навігації та роботи в терміналі.

## Команди / Код

```bash
echo "alias cls='clear'" >> ~/.bashrc && source ~/.bashrc
echo "alias ll='ls -la'" >> ~/.bashrc && source ~/.bashrc
echo "alias nginx='cd <nginx_path>'" >> ~/.bashrc && source ~/.bashrc
```
